# Data analyst

## Описание:
В репозитории представлены часть моих проектов по пройденному курсу [Аналитик данных](https://practicum.yandex.ru/profile/data-analyst-plus/) от Яндекс.Практикума.

## Основные инструменты и навыки, полученные при обучении:
- Языки: Python, SQL
- Анализ данных: библиотеки Pandas, NumPy
- Визуализация: Matplotlib, Plotly, Seaborn
- Построение дашбордов: Tableau
- Метрики юнит-экономики, когортный анализ
- А/В-тестирование
- Работа с гипотезами
- Машинное обучение ML
